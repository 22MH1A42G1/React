## React Router

React Router is a powerful library for managing routing in React applications, enabling seamless navigation between different views and components.

```
npm create vite@latest rapp1

code .
```

👉 Update to latest v6

```
npm i react-router-dom@6
```

👉 run server on local

```
npm run dev
```
